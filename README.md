# Agriculture Services Inventory System

## 📦 Overview

The **Agriculture Services Inventory System** is a web-based application designed to manage, monitor, and organize agricultural supplies and inventory stocks. The system helps improve stock management, inventory tracking, and recordkeeping for Agriculture Services.

It aims to provide an efficient and organized way to monitor available supplies, manage stock movements, and maintain accurate inventory records.

## 🎯 Objectives

- Efficiently manage agricultural supplies and inventory stocks.
- Monitor available stock quantities.
- Track stock-in and stock-out transactions.
- Maintain organized inventory records.
- Improve inventory monitoring and reporting.
- Support efficient management of Agriculture Services supplies.

## ⚙️ Features

- **Inventory Management** – Manage and organize agricultural supplies.
- **Stock Monitoring** – Monitor available inventory quantities.
- **Stock-In Management** – Record incoming supplies.
- **Stock-Out Management** – Track released or distributed supplies.
- **Inventory Records** – Maintain organized stock information.
- **Inventory Reporting** – Support inventory monitoring and management.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 💻 Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Bin95-dev/Agriculture-Stock-Inventory.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Agriculture-Stock-Inventory
   ```

3. Open `Agri-Inventory.html` in your web browser.
